# Security Policy

## Reporting a vulnerability

Please do **not** disclose suspected vulnerabilities in public issues, release comments, or discussions.

Use GitHub’s private vulnerability-reporting facility for this repository when it is enabled. If it is unavailable, contact the repository owner privately through GitHub with:

- A clear description of the issue
- Affected version(s)
- Reproduction steps or proof of concept
- Potential impact
- Any suggested remediation

## Supported versions

Only the latest production release receives security updates. Pre-release/alpha builds are not recommended for operationally important flights.

## Release integrity

Release assets should be obtained only from this repository’s Releases page and verified against the published SHA-256 checksum. Do not run installers from forks, mirrors, or unverified links.
